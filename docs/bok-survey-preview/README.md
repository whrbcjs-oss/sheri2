# 한국은행 기업경기조사 · 검토용 시안

기존 프로그램은 변경하지 않았습니다. 이 폴더는 가상 회사·가상 응답을 사용한 화면 및 출력 배치 시안입니다. 원본 PDF, 실제 연락처와 실제 응답을 포함하지 않습니다. HTML의 저장·회사 선택·월 선택은 실제 데이터베이스와 연결되지 않았으며 인쇄 화면도 고정 예시입니다.

## 원본 양식 분석

A4 세로 한 장. 기업 기본정보(회사명·전화·작성일·주소·주공장 소재지·주요제품 2칸·수출비중·상시 종업원·작성자·이메일·부서·직위), 기관 기입란, 응답 11개로 구성됩니다. 기관 기입란은 사용자 입력에서 제외합니다. 주소는 변경 시 기재하는 원본 지침을 반영합니다.

|항목|판단 기준|당월·전망 선택지|
|---|---|---|
|인력사정|해당월 수준|과잉 / 적정 / 부족|
|매출규모|전년 동월 대비|확대 / 비슷 / 둔화|
|채산성|전월 대비|호전 / 비슷 / 악화|
|자금사정|전월 대비|호전 / 비슷 / 악화|
|업황|계절요인 제외, 귀사 업황|좋음 / 보통 / 나쁨|

각 항목에 당월 동향과 익월 전망을 각각 입력합니다. 경영애로는 원본 14개 보기 중 1개를 선택하며 '기타'는 설명을 입력하도록 개발합니다. 원장 금액만으로 응답을 자동 확정하는 항목이 아닙니다.

## 개발 제안

상단 프로그램 선택에 한국은행 기업경기조사를 추가하고 왼쪽에 월별 조사표 작성 / 작성 내역·출력 / 회사 기본정보를 둡니다. 작업 화면은 하단에 유지합니다. 회사·조사월별로 분리 저장하고 익월 전망은 조사월 다음 달로 자동 계산합니다(12월→다음해1월 포함). 신규 작성은 미응답 상태에서 시작하며 전월 복사는 명시적으로 실행하고 검토합니다. 기존 월 재저장은 변경 이력을 남깁니다.

월별 목록에서 작성 중 / 출력 완료 / 팩스 발송 기록을 구분합니다. 출력은 두 회사 각각 A4 한 장이며 두 회사 일괄 출력도 제안합니다. 이 시안의 출력물은 원본 항목과 표 배치를 참고한 재구성 예시이며 제출 양식 확정본은 아닙니다.

팩스 흐름은 A4 인쇄 또는 PDF 생성 → 사용자가 직접 팩스 발송 → 발송일·수신번호·메모 기록입니다. 발송 기록은 실제 전송 성공 증명이 아닙니다. 자동 팩스가 필요하면 별도 서비스 연결 및 비용·계정을 확인해야 하며 시안에는 연결하지 않았습니다. 수신처는 회사별로 설정하여 다른 담당 본부에도 대응합니다.
