# Sheri2 개발·배포 브랜치 운영

이 저장소의 개발 원본과 사용자 설치 파일을 다음처럼 구분합니다.

- `main`: 안정본과 기존 이력 보관
- `codex-development`: 실제 Python 개발 원본 통합
- `download-20261114-17`: Windows 설치용 업데이트 ZIP 배포

## 작업 원칙

1. 새 기능과 오류 수정은 `codex-development`에서 소스 단위로 작업합니다.
2. 구문 검사와 기능별 회귀 검사를 통과한 변경만 커밋합니다.
3. 사용자 확인이 끝난 배포본은 버전 ZIP으로 만들고 다운로드 브랜치에 올립니다.
4. 설치기는 기존 DB와 사용자 자료를 수정하지 않으며, 변경 전 코드를 백업합니다.
5. `main` 반영은 안정화가 확인된 뒤 별도 병합으로 진행합니다.

## 현재 동기화 상태

- 개발 브랜치는 생성되어 GitHub와 연결되었습니다.
- 실제 사용 중인 전체 프로그램 소스 ZIP을 수집한 뒤 최신 운영본으로 동기화합니다.
- 동기화 전에는 배포 ZIP이 저장된 `download-20261114-17` 브랜치를 운영 배포 이력으로 사용합니다.

향후 화면 테마 선택 기능도 이 개발 브랜치에서 관리합니다.
